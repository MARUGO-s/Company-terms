# フードコート 来客・売上予測モデル

更新: 2026-09-10。本番の数値予測は `forecast-audit-v1`。詳細は [FOODCOURT-FORECAST-AUDIT.md](./FOODCOURT-FORECAST-AUDIT.md) を唯一の数値予測・評価正本として参照する。

## 現在使っている方式

安全補正乗算（`mult-factor-v4-safe`）、直近4回同曜日（`weekday-4-v1`）、類似日（`similar-days-v1`）、客数・売上別の正則化回帰（`ridge-direct-v1`）、3候補の等重み平均（`ensemble-v1`）を同じ発行時点で計算し、当日から14日先まで計75件を固定保存する。初期採用は安全補正乗算。モデル構造・定数・入力を変えた場合は新しいIDにして評価を分ける。

## 旧仕様から変わったこと

| 項目 | 旧方式（現行ではない） | 現行 |
| --- | --- | --- |
| 候補 | GLMと乗算の2方式 | 5方式を同時発行 |
| 採用判断 | バックテストの短期勝敗で日々切替 | 朝の事前予測に対する確定実績で月曜に判定 |
| 精度 | 全履歴・混在MAPE中心 | 方式・先行日数・対象期間を揃えたWAPE/MAE/偏り |
| 保存 | 過去予測の再計算と上書き | 発行時点の予測・入力を改変不可台帳へ保存 |
| 予測幅 | MAPEや暫定割合 | 同方式・同先行日数の絶対誤差に基づく経験的80%幅 |
| 動員・季節性 | 動員や年周期・二次トレンドを使用 | 事後動員を不使用。年周期・二次トレンドを外挿しない |
| 画面の自信表示 | 点数・星・モデル変更を改善表示 | 母数、不明入力、参考と本番の区別を表示 |

## 採用条件と制約

主評価は朝の1日前予測・直近28暦日。月曜日に、現行・候補・同曜日基準の共通21日以上で客数と売上のMAEがともに現行より5%を超えて改善し、前後半（各7日以上）でも両方改善することを確認する。同曜日基準以外の候補は同曜日基準にも両方勝つ必要がある。採用後28日は再切替を待つ。条件未達なら現行方式を維持する。

学習には発行日より前の完了実績のみを使う。過去再計算の天候・イベントは更新後の値なので、未来の本番精度の証拠にはしない。データ増加による必然的な改善、台風の因果、80%区間の的中率を保証しない。
